# Security Policy

Career Skills handles workflows that can involve personal data and external
actions. Do not include real resumes, mail, calendar records, recruiter
messages, credentials, access tokens, or application answers in public issues.

Report a security issue privately through GitHub Security Advisories for this
repository. Include the affected version, a minimal synthetic reproduction,
and the expected safety boundary. Do not test against third-party accounts or
services without authorization.

The bundled validator is local and network-free. Skills may route an agent to
host-provided browser, mail, calendar, or job-source tools, but this repository
ships no credentials and grants no standing authority to send, submit, book,
accept, pay, or delete.
